# Station upgrade modules

**Where do you buy class S upgrade modules?** At the technology merchants of an inhabited [space station](/guides/space-stations). Each class S starship module is on sale at {{shipOne}} of stations, and the system's wealth does not move that chance. A station that sells Launch Thrusters, Pulse Engine, Hyperdrive, Starship Shield, Phase Beam, and Infra-Knife all at class S is {{sixOneIn}} stations: real, and rare.

## Starship modules

<!-- widget:starship -->

Every station sells the class C Launch Thrusters, Pulse Engine, Hyperdrive, and Starship Shield modules, and all four reactors. Every other module, at every class, is a pick of the station, and each has the same chance. There is no class roll: a Hyperdrive Module at S is its own item on the list, beside the one at B and the one at A.

## Why wealth does not matter

A merchant's stock has a fixed size range and draws from one list, and no part of that reads the system's wealth, economy type, conflict, or race. Wealth only sets how many of an item a merchant holds, and for an upgrade module that is one at every wealth. A wealthy system pays more class S ships and multitools, as [economy](/guides/economy) shows, but not more class S modules.

Each station keeps its stock for good. These odds hold for any station; which stations sell everything at class S is not researched yet.

## Pirate stations

A pirate station's merchant shows {{pirateShown}} of {{pirateAll}} suspicious modules, so each is on sale at {{pirateOne}} of pirate stations. How strong a suspicious module is against a class S one is not researched yet.
