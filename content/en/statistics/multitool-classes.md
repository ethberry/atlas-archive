# Multitool classes

**Where do you find a class S multitool?** In medium, high, and pirate wealth systems. A low wealth system holds no class S tool, {{lowS}}, and an Uncharted one pays no tool at all. Medium wealth gives {{mediumS}}, high {{highS}}, and pirate {{pirateS}}. Pirate systems are also the most class C of all, {{pirateC}}, against {{highC}} at high wealth.

[Wealth](/guides/economy) sets the odds, and the source does not: shops, monoliths, camps, and pillars pay the same four classes. Royal tools are the exception, as [multitool types](/guides/multitool-types) shows. The catalog lists [multitools with adjacent supercharged slots](/tool), each with the portal glyphs to pick it up.

## Same cabinet, another tool

A cabinet keeps its class and its supercharged slots, but the tool inside depends on where you started the session: every planet of the system and the space station give a different one. So if a shop, a monolith, or a camp holds a good class but not the type you want, save on another planet or aboard the station, load that save, and fly back. The same cabinet now holds another tool, at the same class and on the same slots. A staff does not change this way: it depends on the head you fit.

## Class and damage

The game uses one roll for a tool's class and its damage. Class S takes a share from 0.99 at medium wealth, from 0.98 at high wealth, and from 0.15 to 0.20 in a pirate system. Low wealth gives no class S at all. So a tool found at class S in a pirate system is always weak in damage for its type, and one from any other system sits at the top. The ranges are under [base stats](/guides/multitool-stats).

A Sentinel pillar uses that roll too: it pays a Royal only past 0.85, which is where class A lies. That is why most Royals are class A.

A class S tool can still be weak. [Multitool stats](/guides/multitool-stats) shows how far each stat can go.
